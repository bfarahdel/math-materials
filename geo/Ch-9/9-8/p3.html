Problem 3

Write the Equation of a Parabola

Write an equation for each parabola.

3. focus (−2, 0), directrix x = 2

The directrix is vertical, so the axis of symmetry is horizontal. The equation is of the form (y − k)2 = 4p(x − h).

Use the focus and directrix to find the values of h, k, and p.

The focus is (h + p, k) = (−2, 0), so k = 0 and h + p = −2.

The directrix is x = h − p, so h − p = 2. Solve the system to find h and p.

h + p = −2
h − p = 2
2h = 0
h = 0
h + p = −2
0 + p = −2
p = −2

Substitute to find the equation.

(y − k)2 = 4p(x − h)
(y − 0)2 = 4(−2)(x − 0)
y2 = −8x

The equation is y2 = −8x or x = −18y2.
