Problem 2

Solving a triangle with $SSS$ (Side-Side-Side) using the Law of Cosines.

The Problem

Given a triangle with sides $a = 20$ (side $BC$), $b = 14$ (side $AC$), and $c = 10$ (side $AB$), find the measures of the angles $A$, $B$, and $C$.

Calculation

1. Find angle $A$ using the Law of Cosines: $\cos(A) = \frac{b^2 + c^2 - a^2}{2bc}$

$$\cos(A) = \frac{14^2 + 10^2 - 20^2}{2(14)(10)} = \frac{196 + 100 - 400}{280} = \frac{-104}{280} \approx -0.3714$$ $$A = \arccos(-0.3714) \approx \mathbf{111.8^\circ}$$

2. Find angle $B$ using the Law of Cosines: $\cos(B) = \frac{a^2 + c^2 - b^2}{2ac}$

$$\cos(B) = \frac{20^2 + 10^2 - 14^2}{2(20)(10)} = \frac{400 + 100 - 196}{400} = \frac{304}{400} = 0.76$$ $$B = \arccos(0.76) \approx \mathbf{40.5^\circ}$$

3. Find angle $C$ using the angle sum property:

$$C = 180^\circ - (111.8^\circ + 40.5^\circ) = \mathbf{27.7^\circ}$$

Final Results:

$A \approx 111.8^\circ, \quad B \approx 40.5^\circ, \quad C \approx 27.7^\circ$
